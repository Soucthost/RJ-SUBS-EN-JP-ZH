# RJ-SUBS.CLOUD work metadata

Public metadata export for indexed RJ voice and ASMR works.

- Site: https://rj-subs.cloud/dataset
- Subtitle hub: https://rj-subs.cloud/subtitles
- Format: CSV and JSON
- Scope: metadata only. No audio, cover files, or subtitle text.

## Fields

| field | meaning |
|---|---|
| rj_id | DLsite RJ product ID |
| title | indexed work title |
| maker | circle / maker name |
| cv | voice actor credit |
| release_date | indexed release date |
| duration | indexed duration |
| has_tracks | 1 when a track list is indexed |
| has_subtitles | 1 when a VTT subtitle archive exists |
